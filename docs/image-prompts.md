# Codex 画像生成プロンプト集（日本語版）

サイト全体の世界観を揃えるため、**すべてのプロンプトに共通スタイルを含めています**。
生成した画像は指定のファイル名（拡張子 `.jpg`）で保存し、`public/images/` に入れてください。

## 使い方

1. 下の各プロンプトをCodexにそのまま貼り付けて生成（アスペクト比の指定を忘れずに）
2. 気に入るまで再生成（【共通スタイル】の部分は変えない）
3. 指定ファイル名で `public/images/` に保存
4. Claude Code に「画像を差し替えて」と伝えれば、参照パスの更新（.svg → .jpg）を行います

## ⚠️ Before/After（ba-1.jpg / ba-2.jpg）について

**AI生成の人物写真を「お客様の変化」として掲載するのはおすすめしません**（実在しない成果の提示になり、景表法上もリスクがあります）。以下のどちらかを推奨します：

- **推奨**: 実際のお客様の写真（掲載許可を得たもの）を使う。用意できるまで現在のプレースホルダのまま公開を待つ
- **代替**: セクション自体を「お客様の声（テキスト）」に置き換える。その場合は Claude Code に指示してください

どうしてもイメージ画像を使う場合は「写真はイメージです」の注記を必ず残してください（現在のサイトには記載済み）。
